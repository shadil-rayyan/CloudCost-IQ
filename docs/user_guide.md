# User guide

- **Overview:** spend KPIs and freshness; mixed currencies/bases are not summed into misleading totals.
- **Import Billing Data:** upload supported exports, review validation/preview, confirm import. Keep real/demo/test datasets labelled correctly.
- **Cost Analysis:** filter by provider/account/service/region/date/currency/cost basis; export tables.
- **ML Predictions:** shows “Forecasting is not yet available…” until a validated production model bundle is registered. With a bundle, displays historical + P10/P50/P90, scope/currency/cost basis, model version/date, metrics/uncertainty, and clear errors for insufficient history or cohort mismatch.
- **Anomaly Detection / Cost Optimization:** transparent statistical/rule logic in MVP 1/2; no automatic cloud changes and no fabricated savings.
- **Import History / Data Quality:** upload lineage, coverage, duplicates/warnings, missing/incomplete periods.
- **Settings:** workspace/reporting preferences; never stores cloud credentials for MVP 1/2 uploads.
